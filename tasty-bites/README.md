# 🍽️ Tasty Bites

A modern restaurant landing page built with semantic HTML5 and CSS, developed as part of my Frontend Development training with Zihntech Academy.

---

## 📸 Overview

Tasty Bites is a restaurant landing page featuring:
- Responsive navigation bar
- Hero section
- About section
- Popular dishes
- Testimonials
- Food gallery
- Latest articles
- Footer with contact information

---

## 🚀 Features

- Semantic HTML5 structure
- Accessible markup (ARIA labels, semantic landmarks)
- Mobile navigation button
- Font Awesome icons
- Reusable card layouts (dishes, testimonials, articles)
- Organized, readable code

---

## 🛠 Technologies Used

- HTML5
- CSS3
- Font Awesome
